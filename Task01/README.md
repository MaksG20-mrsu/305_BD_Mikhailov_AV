# Структура файлов данных

В данном каталоге содержатся файлы исходных данных:
* `ratings.csv` — оценки пользователей (поля: `userId`, `movieId`, `rating`, `timestamp`).
* `movies.csv` — информация о фильмах (поля: `movieId`, `title`, `genres`).
* `tags.csv` — пользовательские теги к фильмам (поля: `userId`, `movieId`, `tag`, `timestamp`).
* `links.csv` — соответствие идентификаторов фильмов внешним системам (поля: `movieId`, `imdbId`, `tmdbId`).
