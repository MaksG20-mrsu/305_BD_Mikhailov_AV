# Лабораторная работа 2. ETL и инициализация БД SQLite

## Требования к окружению
* Интерпретатор Python 3.x
* СУБД SQLite 3 (sqlite3 CLI)
* Оболочка Bash (macOS / Linux / Git Bash для Windows)

## Инструкция по запуску
Для генерации SQL-скрипта db_init.sql и автоматического разворачивания базы данных movies_rating.db выполните:

./db_init.bat
